## About ArkheOS

A debloated Windows 11 25H2 ISO — a clean Microsoft image combined with the ArkheOS playbook via [AME Wizard](https://ameliorated.info/), 

Grab it from [arkheos.xyz](https://arkheos.xyz)

## What the ISO BOOK does

1. Downloads the **Arkhe Toolbox** (`Post.exe`) to your desktop

2. Removes Microsoft Apps / Xbox Apps

3. Applies pre tuned tweaks for lower input latency and higher, more consistent frames in game

## Installing

1. Go to [arkheos.xyz](https://arkheos.xyz) and download the latest ArkheOS ISO.
2. Flash it to a USB drive using a tool like [Rufus](https://rufus.ie/).
3. Boot from the USB and install. See [INSTALL.md](INSTALL.md) for step-by-step instructions.
4. Once Windows boots, use the **Arkhe Toolbox**  after applying playbook to download whatever apps needed.

## Requirements

- Windows 11, build 26200 (25H2) — ArkheOS
- Internet connection during install
- A USB drive, 8GB or larger recommended, for flashing the ISO
